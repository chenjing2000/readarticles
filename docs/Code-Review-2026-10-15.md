## 推荐可靠性修复：并发词表保存

原实现在序列化前和替换前校验指纹，但同一文件的多个本程序写者没有互斥。检查和替换不是一个原子操作；并发回归在修复前实际出现文件访问异常。此证据确认并发保存不能稳定按预期拒绝过期写者，并未单独证明发生过静默数据丢失。

Save 现在用绝对路径、大小写归一和 SHA256 生成当前 Windows 会话内的命名 Mutex，在持有互斥时检查指纹并完成原子写入。等待期间前一写者已提交时，后续写者会收到原有的重新打开提示。处理 AbandonedMutexException 后仍重新检查文件，finally 释放所有权。没有新增公共接口、锁框架或数据格式。

回归用屏障同时启动八个写者，覆盖首次创建和已有词表，要求恰好一个成功，其余收到版本冲突，结果可完整读取且无临时文件残留。最终版本还混用绝对大写路径和相对路径，验证常规路径归一。

命名 Mutex 的跨进程语义用于协调同一 Windows 会话内本程序的写者；本次回归直接运行的是多线程写者。未做独立多进程、跨会话或网络共享验收。它不能阻止不采用该锁的外部编辑器在最终指纹检查之后替换文件，也不统一链接或网络映射的路径别名。
