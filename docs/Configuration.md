# Configuration

ReadArticles stores its current settings in `userdata/config/settings.json`, inside the portable directory beside the executable. All app-owned config, backups, logs and WebView2 data live under `userdata/`, never in the selected article library.

## Breaking upgrade and recovery

The setting format is structured JSON with `Appearance`, `Audio`, `Library` (the selected library path or null) and `ExcludedFolders` (a string). Older flat formats and old executable-sibling files are not imported. An obsolete file at the current location is replaced with defaults; no account-specific data is read. Normal current-schema saves are atomic and rotate one verified pre-save backup at `userdata/backups/settings/settings.json.bak`. Malformed current JSON is preserved as a uniquely named `.corrupt` file, with verified-backup recovery attempted before default initialization. The same current-schema check (object-valued Appearance and Audio) applies to saves and backup validation. Explicit restoration rejects invalid backups; if the current source is invalid or obsolete, it first preserves a verified separate recovery copy and restores without rotating the valid backup. Normal saves reject obsolete or structurally invalid existing files; startup retains the established obsolete-format reset policy. On I/O failure, settings remain in memory and a warning is reported.

Pane widths are owned by PaneLayout, separate from ReaderSettings, and are session-only (250/300 DIP default, each 200–400 DIP); the article has a 200-DIP minimum, each splitter is 3 DIP, and the native browser host has a 403-DIP minimum. Window size, active article and highlighting are not saved.

## Native settings dialog

The cog next to 选择图书馆 opens the modal window titled 设置. It uses the built-in WPF Fluent theme, fixed 500 x 540 DIP window size, four 72/140/72/140 DIP functional columns with a 20-DIP center gap, and close-only window chrome. Esc/Cancel discards the draft. Restore Defaults edits the draft; Save applies it once. Eight color properties are each chosen from five evenly spaced 20-DIP balls in a 140-DIP row, without hexadecimal text entry. The first color of each row is the default:

- Title, body and meaning text: #283747, #344054, #3F4750, #315247, #513D4D
- Word head: #B7394D, #9D3E68, #7D50A1, #1F6795, #8B593B
- Phonetics: #0A7785, #256CA5, #38735A, #7657A0, #995431
- Background: #F8F8F6, #F0F3F7, #F7F1E6, #EFF5F0, #F1F0F7
- Selection background (native CSS `::selection`): #DDE8F2, #E5EDE0, #F3E9DC, #EBE5F2, #F2E5E7 (default #DDE8F2)
- Script playback background (`Appearance.Body.ScriptColor`): #F6EDC2 (default light wheat), #F5E4D6 (light apricot), #E1EEDB (light green), #E0ECF4 (light blue), #ECE6F3 (light purple). The existing settings field and layout are retained; the playback swatches use a dark #283747 checkmark.
- Retired Script colors normalize in memory, case-insensitively: #B64550/#A33D30/#E02020 → #F6EDC2; #A45A2C/#D65A00 → #F5E4D6; #53713C/#008A48 → #E1EEDB; #0066E6 → #E0ECF4; #856300/#8A36D1 → #ECE6F3. Other invalid values fall back to #F6EDC2 as before. Normal loading does not rewrite the settings file; subsequent saves use the existing persistence and backup mechanism. Other preferences are unchanged.

Title defaults: Newsreader 18px bold, 1.7 line height (1.6/1.7/1.8), 16px after (16/18/20). Body defaults: Newsreader 15px, 1.7 line height (1.6/1.7/1.8), 16px after (14/16/18), 2em first-line indent (0/1/2/3). Word head: Newsreader 16px semibold. IPA: 14px. Meanings: Source Han Serif SC (思源宋体), 15px, 1.5 line height (choices 1.5/1.6/1.7). All five text sizes use centered 100-DIP single-line inputs with a px label: ASCII digits only, at most two characters, valid integers 10–40 inclusive. Empty or out-of-range drafts prevent Save, focus the corresponding input and show a notice; invalid paste is rejected as a whole. Invalid persisted sizes normalize to their respective defaults. Reset restores the five defaults; Cancel discards edits. English font choices, in order, are Newsreader (default), Source Serif 4, Georgia, Nunito and Microsoft YaHei UI. Chinese meaning font choices are Source Han Serif SC (思源宋体, default) and Microsoft YaHei. Existing valid selections are retained; retired or invalid values normalize to the respective new default without rewriting the file on load. Installed-font checks apply to Newsreader, Source Serif 4, Georgia and Nunito; unavailable choices show a nonmodal "未检测到字体 {name}。" message and keep the previous usable font. Missing English draft fonts use the first available choice in the same order. WebView2 places the selected font first, followed by the remaining choices in order and sans-serif; missing Chinese fonts fall back silently without changing the saved choice. Fonts are installed by the user, not bundled. Default accent UK, fixed 100% audio output, forward steps 4/7/10/15s, backward 5/8/11/16s. The first seek step in each list is the default. The intervals govern the exclusive main-window arrow shortcuts. There is no speed or volume control.

The final “其它” section contains a single-line “需排除的文件夹” text box (112/332 DIP columns) without a clear button. The default is `audio, cache`; existing structured settings lacking the field keep their other values and receive this default. A blank string disables custom exclusions. The four separators are `,`, `;`, `，`, `；`; surrounding whitespace and empty entries are removed, internal spaces retained and duplicates ignored case-insensitively. Names must be valid individual Windows folder names, not paths; the four separators cannot occur inside a name. Invalid input prevents Save and shows a message. If a structurally valid on-disk configuration contains an invalid exclusion-name string or a non-string, non-null exclusion field, only this field falls back to its default with a warning. The original bytes stay unchanged until a successful save, which preserves them in a separate `.corrupt` recovery copy without rotating the last valid backup. Structural JSON errors still use the existing full recovery procedure. Restore Defaults resets the draft. See [Library Layout](Library-Layout.md) for navigation behavior.

## Reading UI and files

The dialog keeps 13-DIP parameter labels and option text, 12-DIP unit labels, 15-DIP section titles, and left-aligned controls. The selection-add glyph size is configurable in the body settings as 0.65, 0.70, 0.75 or 0.80 em (default 0.65), relative to the body font size. It occupies the top-left of a 24 CSS-px click region and sits 1 CSS px right and 0 px below the final selected fragment. A single requestAnimationFrame loop validates the current browser selection before updating the button position at up to approximately 60 Hz while the selection is visible; there is no configurable refresh period. The three bottom rails are 48 DIP high and SVG toolbar buttons are circular and borderless. Rounded vocabulary highlights use Range rectangles without changing text nodes. Script playback uses the selected background color in SVG rectangles under the unchanged text; completed same-line timed units join intervening whitespace. Playback backgrounds cover overlapping vocabulary highlights; rewinding or stopping reveals those highlights again. Stopped audio clears progress and disables seeking.

All Passage/Script/vocabulary JSON and M4A/MP3/WAV media remain in the user-selected external library. Only the active vocabulary companion is edited; verified pre-save vocabulary backups live under `userdata/backups/vocabulary/`, with one normal backup per normalized source-path hash. Passage, Script and media are read-only. Portable publication preserves existing `userdata/` but does not migrate old directory layouts.
