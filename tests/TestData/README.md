# ReadArticles test data

This directory is the single checked-in source for fixed application test inputs.
The test runner treats these files as read-only and copies the required data into
an isolated directory under the operating system temporary directory.

## Layout

- `Library/`: fixed article and vocabulary JSON used by navigation, rendering,
  vocabulary, and reader regression tests.
- `Audio/audio/`: the shared vocabulary pronunciation pool.
- `Audio/audio_sentences/`: the shared sentence pronunciation pool.

The main regression article is:

`Library/The Economist/2026-09-26/When America walks away/`

It contains 13 paragraphs, 62 stable sentence IDs, and 120 vocabulary entries.
The audio pool contains UK and US recordings for every vocabulary entry and for
all sentence IDs except `s011`. The two `s011` recordings are intentionally
absent so the application can be tested for lazy, per-sentence missing-audio
warnings. Do not add those two recordings unless the corresponding regression
expectations are deliberately changed.

A second article is retained in `Library/` for navigation and article-switching
checks. WAV-only and other exceptional playback scenarios are generated by the
test code in temporary working directories; they are not stored as duplicate
media collections.

## Rules

1. Do not edit these files during a test run. Tests must work on temporary copies.
2. Keep audio names aligned with the application's derived naming rules:
   `word-stem_uk|us.mp3` and `SID_uk|us.mp3`.
3. MP3 is the normal shared fixture format. WAV fallback cases are generated or
   assembled in isolated temporary test directories.
4. Test screenshots, reports, and logs belong in the repository's `artifacts/`
   directory, never beside these source files.
5. When intentionally changing a fixture, update this README and the relevant
   regression assertions in the same change.

## Expected inventory

- 2 fixed article JSON files and 2 matching vocabulary JSON files.
- 120 unique vocabulary stems, each with UK and US MP3 recordings.
- 61 sentence IDs with UK and US MP3 recordings (122 files).
- 2 intentionally absent sentence recordings: `s011_uk` and `s011_us`.
